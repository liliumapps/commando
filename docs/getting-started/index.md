# Getting started

Two short steps take you from zero to summoning commands with a keystroke:

<div class="grid cards" markdown>

-   :material-download: __1. Install & set up__

    ---

    Build the single static binary, drop it on your `PATH`, and add one `eval`
    line to your Zsh, Bash, or Fish config for the `Ctrl-G` summon widget.

    [:octicons-arrow-right-24: Installation & setup](installation.md)

-   :material-play: __2. Take it for a spin__

    ---

    Search, fill in a parameterized command, and run it.

    [:octicons-arrow-right-24: Quickstart](quickstart.md)

</div>

!!! info "Requirements"

    **Go 1.25+** builds the binary (pure Go, no CGO — a single static binary).
    The interactive summon widget supports **Zsh, Bash, and Fish**; the CLI also
    works in other shells and prints the assembled command to stdout.
